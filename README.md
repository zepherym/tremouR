# tremouR

A tool that enables communication of data over sound between devices.

It reads in some data (currently a file) and encodes the data into a sign wave using signal modulation. Then that signal get played as a sound using the speakers of the device.

On the other machine the microphone listens to the sound demodulates the signal into data and outputs it.
